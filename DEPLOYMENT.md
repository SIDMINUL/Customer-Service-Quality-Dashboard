# Deployment

This project is a Power BI dashboard rather than a server application.

## Publish to Power BI Service

1. Open `Customer_Service_Quality_Dashboard.pbix` in Power BI Desktop.
2. Confirm the data model and visuals refresh successfully.
3. Sign in to your Power BI account.
4. Select **Publish** and choose a workspace.
5. Open the published report in Power BI Service.
6. Configure scheduled refresh if the data source is hosted and your account/workspace supports it.

## Portfolio sharing

For a public portfolio, use Power BI's supported public sharing option only when the dataset contains no confidential or personal information. Otherwise share the report privately or export selected visuals as images/PDF.

Supporting analysis files in this repository include Python, SQL and Excel artifacts.
